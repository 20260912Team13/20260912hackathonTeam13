# コンセプト

Mars Builderの核となる思想、世界観、審査員に伝えるメッセージをまとめる場所です。

## 一番伝えたいこと

火星の街は、NASAや建築家だけが作るものではなく、自分たち一人ひとりが作れるかもしれない。

## プロダクトを説明する一文

2036年、火星の街は専門家だけが作るものではない。暮らしたい未来を言葉にすれば、AIがそれを建築へ変えてくれる。

## タグライン

```text
Design life on Mars.
```

## 体験の中心

ユーザーが考えるのは、建築条件ではありません。

```text
地球を眺めながら、友達と食事できる場所が欲しい。
```

このような人間の願望を、AIが建築可能な要件へ翻訳します。

```text
人間の願望 → AIによる建築要件化 → ロボットによる建設
```

## 役割分担

- 人間: どんな火星に住みたいかを想像する。
- AI: 曖昧な願望を、建築名、面積、人数、構造、安全性、必要レゴリス量、プリント時間へ変換する。
- ロボット: 火星のレゴリスを使って、3Dプリント建築する。

## 判断基準

迷ったら、次の問いで判断します。

```text
それは、「自分も火星の街を作れる」という感覚を強めるか？
```

YESならやる。NOならやらない。

## 伝え方

- 宇宙建築の正確さより、未来を自分ごとに感じられることを優先する。
- 専門用語より、「こんな場所が欲しい」という日常の言葉を優先する。
- AIをチャットボットではなく、願望を建築へ翻訳する存在として見せる。
- 1人が1つの場所を作り、それが集まって街になる未来を見せる。
