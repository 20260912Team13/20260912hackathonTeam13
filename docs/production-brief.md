# Mars Builder 制作ブリーフ

## 一番伝えたいこと

NASAや建築家だけでなく、火星に暮らす一人ひとりが街づくりに参加できる。

## プロダクトを説明する一文

2036年、火星の街は専門家だけが作るものではない。暮らしたい未来を言葉にすれば、AIがそれを建築へ変えてくれる。

## 体験のゴール

ユーザーが願望を入力してから、自分の建物が火星に完成するまでを体験できる。

## 画面

1. 火星コロニー
   - 火星の風景
   - CTA: 火星にどんな場所を作りたいですか？

2. AIチャット / 入力
   - ユーザー: 地球を眺めながら、友達と食事できる場所が欲しい。
   - AI: あなたの場所を設計しています...

3. 建築提案
   - EARTH VIEW DINING POD
   - 12人
   - 45平方メートル
   - レゴリス 18.4t
   - プリント時間 31h
   - CTA: 火星に配置する

4. 配置場所
   - クレーターサイド
   - 地球が見える丘
   - 中央コロニー
   - CTA: ここに建てる

5. 建設
   - レゴリス 18.4t
   - 準備完了
   - BUILD
   - レゴリス充填中...
   - 3Dプリント中...
   - 建築完了

6. 完成 / 共有
   - 火星に新しい場所を作りました。
   - Xに共有
   - Instagramに共有
   - リンクをコピー

## 優先順位

1. ストーリーが伝わる
2. 一連の体験が動く
3. ビジュアルが魅力的
4. 技術的に凝る
