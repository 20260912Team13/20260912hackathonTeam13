# デザイン

Mars Builderのデザイン方針、共通コピー、ビジュアル素材の方向性をまとめる場所です。

## キーワード

- ミニマル
- 未来的
- 人間的
- 宇宙
- 静か
- 上質

- 軍事的なSF操作パネル感
- 専門用語の出しすぎ
- 複雑な建築操作
- 機能を盛り込みすぎること
