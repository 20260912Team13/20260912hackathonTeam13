# Design

Design direction and shared copy for Mars Builder.

## Keywords

- Minimal
- Future
- Human
- Space
- Calm
- Premium

## Avoid

- Military sci-fi dashboard
- Too many expert terms
- Complex construction controls
- Overbuilding features

## Core Copy

```text
Design life on Mars.
```

```text
What do you want to build on Mars?
```

```text
I built this on Mars.
```
