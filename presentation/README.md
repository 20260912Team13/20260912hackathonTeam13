## ゴール

```text
火星の街は、NASAや建築家だけが作るものではなく、自分たち一人ひとりが作れるかもしれない。
```

## 発表の流れ

1. 課題: 宇宙都市づくりは専門家だけのものに見える。
2. 転換: 未来の火星住民自身が、自分の街を形づくれるべき。
3. プロダクト: Mars Builder。
4. デモ: 願望 → AI建築案 → 配置 → 建設 → 共有。
5. 実現性: 生成AI、ロボット建築、ISRU、レゴリス利用。
6. 将来像: 一つの場所が集まり、やがて街になる。
