# Webプロトタイプ

Mars Builderのスマホ中心のインタラクティブデモを作る場所です。

## ゴール

MVPの一連の流れを、審査員がスマホアプリのように触れる状態にします。

```text
火星コロニー → AIチャット → 建築提案 → 配置 → BUILD → 完成 / 共有
```

## 実装方針

- まずはフロントエンドだけで作る。
- AI出力はモックでよい。
- 機能数より、1つの強い体験とビジュアルを優先する。
- デモはスマホ画面で見せる前提にする。
